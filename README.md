# Petever

> 보호 중인 동물에게는 새로운 가족을, 길을 잃은 동물에게는 돌아갈 길을.

Petever는 구조동물 공고와 분실동물 신고를 한곳에 모아 사람과 동물이 다시 연결될 가능성을 높이는 서비스입니다. 이 저장소는 Petever가 사용자에게 정확하고 일관된 동물 정보를 제공할 수 있도록 서비스의 정보 기반을 담당합니다.

## Petever가 전하는 정보

- 최근 등록된 구조동물과 분실동물 현황을 구분해 제공합니다.
- 사진, 품종, 동물 종류와 현재 상태 등 공고 확인에 필요한 정보를 전달합니다.
- 여러 곳에서 제공되는 동물 정보를 사용자가 살펴보기 쉬운 형태로 정리합니다.
- 보호 중인 동물은 새로운 가족을 만날 수 있도록, 분실동물은 원래 가족에게 돌아갈 수 있도록 연결을 돕습니다.

## 구조동물과 분실동물

**구조동물** 정보는 보호기관에서 보호 중인 동물과 현재 공고 상태를 안내합니다. 사용자는 사진과 기본 정보를 살펴보며 새로운 가족을 기다리는 동물을 찾을 수 있습니다.

**분실동물** 정보는 가족이 찾고 있는 동물의 신고를 빠르게 확인할 수 있도록 제공합니다. 두 정보를 분명히 나누어 각 상황에 맞는 공고를 쉽게 찾도록 돕습니다.
